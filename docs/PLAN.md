# 初期版の計画と検証

## 開発の必要性
動画を見るだけでは確認しにくい関節の動きと時刻を示す検証用アプリを作る。指導の有用性は未検証。一般公開・有料化は指導者評価を通過するまで行わない。

## 暫定の対象と選択
成人の初級〜中級、静止球へのインサイドパス1回、10〜30秒、固定した横方向の撮影を優先する。未成年への適用は保護者同意と指導者確認の運用を確定後。右足・左足に対応。正面・斜めでは画面内の動きだけを観察し、前後方向の助言を抑制する。
端末内のMediaPipe推論を利用。動画・分析結果はメモリにのみ保持し、削除・再読込で破棄。モデルとWASMの取得には外部通信が発生するが動画は送信しない。LLM利用・学習利用・アカウント・永続保存は初期版に含めない。

## 実装順序
1. 日本語の撮影ガイド、入力検証、削除までのUI。
2. フレーム抽出と姿勢推論を専用Workerで実行、60秒で中止、再試行は利用者が操作。
3. 見切れ・暗さ・画像の鮮明さ・足元の可視性を確認。
4. 蹴り足の最大移動の周辺を場面候補として抽出。接地・接触は確定しない。ユーザーが動画で確認。
5. 画面上の体幹の傾き・骨盤・両足の動きを計測し、測定値を参照した定型助言を最大3件表示。
6. 根拠動画の再生・関節表示・結果削除と異常系を検証。

## 検証前に固定する合格基準（案）
指導者2人が左右各10本の適切な動画と、足元遮蔽・暗所・ブレ・複数人を含む不適切な動画10本を独立評価する。評価者が場面を合意できない動画は別集計し、除外理由を記録。
- 蹴り動作の候補が指導者の指定した区間に入る割合90%以上。
- 表示した観察・根拠の整合率95%以上。
- 助言が実行可能かつ練習目的に合う割合80%以上。
- 足元不可視に対する足の断定0件、測定していない荷重・接触の断定0件。
- 対応ブラウザで完走率95%以上、解析時間の95パーセンタイル60秒以内。
- 削除後に動画URL・分析データ・Workerの参照が残らない。
協力者の合意後、実動画を投入する前に基準を確定する。現在は未実施。

## 残る制約
ボール検出・接触判定・3D重心・荷重・パス精度は未実装。鮮明さは画像のコントラストの目安であり、手ブレを確定するものではない。単眼2Dの閾値は暫定で医学的・競技的な基準ではない。1人以外の動画は再撮影対象。過去比較はF11として次段階。処理費用は外部有料API0円、端末処理時間・フレーム数を表示し、1動画30秒・100MB・1回の解析60秒を上限とする。

## ボール検出の追加（2026-09-30）
上記の未実装項目のうち、ボールの位置検出を追加する。既存のMediaPipe ObjectDetectorと公式EfficientDet-Lite0を使用し、全体画像・足元拡大画像を毎秒6フレームで解析。検出枠と検出フレーム数、根拠時刻を表示する。検出していない時刻や隠れたボールを推測で埋めない。一般のスポーツ用ボール検出であり、サッカー専用分類や物理的な接触・速度・精度の測定は引き続き行わない。60秒の上限を維持し、サンプルで起動・陽性・陰性の経路を検証する。実際の利用動画での精度評価は別途必要。

## YouTube入力の追加（2026-09-30）
利用者の依頼により、公開動画のリンクと解析区間を入力して読み込む機能を追加。ブラウザではYouTube映像を直接取得できないため、このPCの取得APIで指定した10〜30秒だけを一時取得し、既存の端末内姿勢解析に渡す。取得と解析の責務を分離し、YouTube固有の制約が分析の判定に混ざらないようにする。
yt-dlpで録画済み動画と長さを確認し、FFmpegで720p以下・無音のH.264区間を作る。取得120秒・同時1件・100MBの上限、入力URLの許可リスト、一時ファイル削除を実装。ログイン情報・Cookieは利用しない。取得制限の場合はファイル入力を案内する。YouTubeリンク入力でも動作分析の撮影条件と検証前という扱いを維持する。
